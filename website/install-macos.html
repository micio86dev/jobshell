Install Jobshell on macOS

Jobshell is not signed with an Apple developer certificate yet, so macOS blocks the first launch. The steps below open it once; after that it starts normally. This applies to Apple Silicon Macs (M1 and later), the only architecture the current build produces.

1. Download and install

  1. Download the .dmg file for macOS from the latest release.
  2. Open the .dmg and drag Jobshell into Applications.
  3. Eject the disk image.

2. First launch (recommended way)

  1. Open Applications and double-click Jobshell. macOS says it cannot verify the app. Click Done.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the message “Jobshell” was blocked to protect your Mac and click Open Anyway.
  4. Enter your Mac password (or use Touch ID). In the dialog that appears, click Open.

On macOS Sequoia and later, right-click → Open no longer bypasses this check. Use the Privacy & Security path above. The button stays available for about an hour after the first blocked attempt.

2b. First launch (Terminal alternative)

If you prefer the Terminal, remove the download quarantine flag from the app only:

xattr -dr com.apple.quarantine /Applications/Jobshell.app
open /Applications/Jobshell.app

The command removes the flag that macOS adds to files downloaded from the internet. It does not change system security settings. Run it only on the app you downloaded from the official repository.

Updates

Each new version is a new download, so the steps repeat the first time you install it.

Something else?

If the app still does not open, send the exact message macOS shows and your macOS version in an issue on GitHub.
